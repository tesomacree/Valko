# Valko
VALKO auttaa opettajia opettamaan opiskelijoita ja seuraamaan heidän tuntiaktiivisuuttaan ja keskittymistään tunneilla. VALKO sisältä kaiken tarpeellisen materiaalin ja aineet opettamiseen ja opiskeluun, VALKO ohjelmiston tarkoituksena on keskittää opetus yhteen sivuun jotta eri nettisivujen väleillä ei tarvitse surffailla.
